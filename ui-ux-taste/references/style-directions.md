# Style directions

Pull 4–6 of these per session, chosen for relevance to the app's domain — don't run the same six
every time. Each entry: name, one-line description, tuned `image_search` query. Query strings are
starting points; add the app's domain word (e.g. "fintech", "recipe app") when it sharpens results.

## SaaS / dashboard / B2B tools

- **Clean SaaS** — high information density, quiet neutral palette, one accent color, generous
  data tables. Query: `"clean SaaS dashboard UI design"`
- **Dark tech / cyber** — dark surface, neon or high-saturation accent, monospace touches, feels
  technical and precise. Query: `"dark mode developer dashboard UI"`
- **Industrial brutalist** — rigid grid, raw borders, utilitarian type, minimal color, feels like
  a terminal or blueprint. Query: `"brutalist web design dashboard"`
- **Soft neumorphic / glass** — frosted surfaces, soft shadows, rounded, calm. Query:
  `"glassmorphism dashboard UI design"`

## Consumer / social / lifestyle apps

- **Playful maximalist** — bold color blocking, illustration, personality-forward type. Query:
  `"playful mobile app UI design colorful"`
- **Editorial minimal** — warm monochrome, typographic contrast, generous whitespace, feels like
  print. Query: `"minimalist editorial app UI design"`
- **Retro / nostalgic** — warm grain, period-specific type and color, deliberately not sleek.
  Query: `"retro nostalgic app UI design"`
- **Native-feeling mobile** — platform-conventional (iOS/Material), high polish, low novelty by
  design. Query: `"native iOS app UI design clean"`

## Ecommerce / marketing / landing

- **Luxury minimal** — huge type, sparse layout, product photography does the talking. Query:
  `"luxury ecommerce landing page design"`
- **High-energy DTC** — bold color, motion-forward, conversion-driven layout. Query:
  `"DTC ecommerce landing page bold design"`
- **Warm craft / artisan** — texture, muted earth tones, handmade feel. Query:
  `"artisan craft brand website design"`

## Portfolio / creative / dev tool

- **Experimental/art-directed** — unconventional grid, motion as a feature, unique per project.
  Query: `"experimental portfolio website design"`
- **Terminal / CLI-inspired** — monospace-first, command-line aesthetic, dev-tool coded. Query:
  `"terminal inspired developer tool UI"`
- **Docs-clean** — like great technical documentation: fast, searchable, low-chrome. Query:
  `"clean documentation website design"`

## Notes on picking a spread

Pick directions that would actually produce different code, not different color swatches on the
same layout — "Clean SaaS" and "Docs-clean" are both minimal but imply different information
density and nav patterns, so they're a valid pair; two minimal-but-pastel options back to back are
not. If the user names a style outright ("something like Linear" / "brutalist but not ugly"),
search for that directly instead of running the generic spread — a query like `"Linear app UI
design"` beats guessing which bucket it falls into.
